1. Added ability to filter tickets by tag
2. Added ability to filter by assignee
3. Added Board Id details in UI
4. Improved documentation with information about closed tickets not appearing on the board

1. Fixed issue preventing changes to assignee for created tickets

4. Fixed incorrect status display in "Tickets" view inside Engagement "Tickets" tab
5. Addressed issue where new tickets were not appearing on the Board
6. Corrected inconsistency in ticket status between Tickets UI and Board
7. Fixed Board UI Ticket Column Status Override Issue on Kanban Board
8. Resolved pagination issues for Tickets View in Engagements
9. Fixed non-functional Status filter in Tickets Tab
10. Corrected title bug where additional text was saved when styles were applied
11. Fixed issue preventing removal of uploaded attachments in created tickets
12. Corrected incorrect month format display
13. Resolved bug where Risk Tickets were created without a title
14. Fixed empty assignee list when no assignee was selected
15. Addressed issue preventing Board deletion
